# Campus Consolação (Rua Marquês de Paranaguá, 111): floor plan sources

Public sources only; PUC-SP was not contacted.

- `vitruvius_rino_levi_planta_*.jpg`: Rino Levi's Instituto Sedes Sapientiae (1940-42), ground and upper floor, redrawn by Ana Paula Koury. https://vitruvius.com.br/revistas/read/minhacidade/18.216/7066 (528x344, low-res)
- `vitruvius_palermo_corte_fachada_bloco_aulas.jpg`: enlarged section and west elevation of the classroom block (cobogó dimensions, 1:100 / 1:25). https://vitruvius.com.br/revistas/read/arquitextos/21.249/8012
- `pucsp_mapa_consolacao.jpg`: PUC-SP site plan of the campus buildings (footprints only). https://www5.pucsp.br/puc-tour/consolacao.php
- `condephaat_res68_2010.pdf`, `conpresp_12_15.pdf`: heritage resolutions. Protected core = auditorium block (1), former dormitory (2), teaching block (3), inner patio (4). The GEGRAN cadastral plan is referenced but not attached.

Government sources checked:
- `geosampa_lote_010.014.0323.json`: city lot record for R. Marquês de Paranaguá 111 (SQL 010.014.0323): land 4,963 m2, built 6,281 m2 (IPTU), non-residential. `geosampa_edificacoes_bbox_lote.json`: GeoSampa building footprints with heights near that lot (2007-14 photogrammetry, 1:5000; not plans). Source: https://wfs.geosampa.prefeitura.sp.gov.br/geoserver/ows (layers geoportal:lote_cidadao, geoportal:edificacao).
- Conpresp 26/2004 annex lists the lot (SQL 010.014.0323); Conpresp 12/2015 and Condephaat SC 68/2010 define the protected blocks. No plans attached.
- Condephaat tombamento process 24371/86 (plus 24371/02) was transferred to the Arquivo Público do Estado de SP, which holds drawers of plans of listed buildings. Not digitised online; consultation is by request (Arquivo Público / Condephaat CEDOC). Fire (AVCB) and permit plans are not public online.

Not publicly available:
- FAU-USP Acervos items 5676 / 6166 / 6167 hold the original sheets (111 sheets, 1:200 to 1:1: plans, sections, elevations) but are catalogued, not digitised.
- No public room-level plans for the later PUC buildings.
- Anelli/Guerra/Kon book *Rino Levi: arquitetura e cidade* (2001) and the Itaú Cultural *Ocupação Rino Levi* catalog likely hold full plans, but no free copy was reachable (the Itaú PDF link on edisciplinas needs a login).
